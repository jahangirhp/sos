# همسایه‌یار logo

White house containing red SOS lettering on a warm red background, with no text.

- `logo-original.png`: original generated artwork.
- `../google-play/icon-512.png`: opaque 512×512 PNG for Google Play.
- Android adaptive launcher: `mipmap-anydpi-v26/ic_launcher.xml`; inset artwork keeps the house inside Android's mask-safe area. Minimum supported Android is API 26.

The notification icon remains a separate monochrome exclamation symbol for Android status-bar legibility.
